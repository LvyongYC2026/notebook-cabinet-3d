## 当前布局

整柜外尺寸为 **宽330 × 深65 × 高185 cm**，采用左135、中央60、右135 cm的三模块布局。

| 区域 | 配置 | 说明 |
|---|---|---|
| 左侧 | 9个开门仓，3列×3层 | 开盖笔记本、透明门与抽拉托盘 |
| 右侧 | 24个抽屉仓，3列×8层 | 闭盖笔记本、透明玻璃/金属双前板与嵌入式拉手 |
| 底部 | 离地35 cm外观水平线 | 左侧随仓门分段，中央随设备门分段，右侧为底部面板上沿 |
| 中央 | 保留原设备仓高度 | 内部高度68 cm，承载服务器、网络与供电控制设备 |

A3、B2、B6、B20初始为空仓，共29台展示电脑。右侧按从上到下、每层从左到右编号B1—B24。

右侧按闭盖电脑 **30 ×21 ×3 cm** 的设计假设布置，承载区域净高 **13 cm**，相当于电脑总厚3 cm加10 cm上方余量。层距16 cm，承托面离地38—150 cm。为避开35 cm底板，右侧最低承托面比外观线高3 cm。35 cm外观线不代表中央设备仓被切分。

## 页面操作

- 顶部切换机要室、整柜和单仓；单仓再选择左侧开门仓或右侧抽屉仓。
- 点击门、抽屉或内部部件，可操作机构、聚焦查看和打开参数浮窗。
- 底部“抽屉前板方案”按钮选择透明玻璃或金属前板，默认透明玻璃；机要室、整柜、右抽屉单仓共用选择，切换时保持抽拉位置和接线状态。
- 右侧一次展开一个抽屉；切换时先收回上一屉。右抽屉行程32 cm。
- 旋转、缩放、透明玻璃、结构剖视及厘米尺寸标注均可开关。
- “布线方案”展示固定电源、蓝色以太网、活动DC与紫色USB短线，并可聚焦单仓接线。
- 空仓保留托盘、适配器和留柜网卡；借出电脑时，USB端停靠随盘卡座，DC端停靠固定卡座。

所有页面长度使用cm；元数据保留原计量单位，GLB坐标使用米。

## 房间与操作空间

机要室净尺寸 **510 ×300 ×280 cm** 属于参考布局设计假设。房间、整柜共用同一个33仓模型；包含门禁门、工作台、座椅、电脑、监控、吊顶与中文标识。

柜前闭合状态预留120 cm操作区。右抽屉前板齐平，抽出32 cm后占用这一区域，名义剩余88 cm；左侧原托盘的前缘关系单独计算，不能套用右侧数值。门扇、电脑取放、人员站位和现场通行仍需另行校核。

参考布局柜后只有10 cm，因此房间模式禁止开启后维护门。查看后侧主干会切换至独立整柜；实际后部维修需先移动机柜。

## 数字资产与验证范围

[当前玻璃/金属双方案Blender工程、脚本及检查报告](hybrid-33bay-glass/README.md)。右侧闭盖电脑按参考图采用银色拉丝上盖、深色圆角底壳、双铰链及侧面接口细节。玻璃与左门共用材质，顶部金属握持带承载嵌入式把手；周框、压条、垫条及共享托盘连接耳构成实际装配路径。本版包含整柜、独立右抽屉仓与机要室/产品双场景工程。左开门单仓继续复用原有精细模型。

检查覆盖仓位数量、模型层级、抽屉联锁、线缆端点与插值、取放状态、抽屉运动采样、设备净空、房间碰撞及页面显示。模型用于方案和交互展示；采样几何检查不替代机械承载、抗倾覆、寿命、电气、温升和具体机型的实机验收。

文件传输路线为笔记本USB→留柜USB网卡→以太网→交换机→服务器。网页不读取或上传笔记本文件，也不把两台USB主机直接相连。供电、网络和锁控容量示意需在器件选型后复核。

## 本地运行与发布

在仓库根目录启动静态服务器：

```sh
python3 -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。不能用`file://`直接打开。GitHub Pages从`main`分支根目录发布，无构建步骤，`.nojekyll`禁用Jekyll。所有网页模型与Three.js依赖使用本站相对路径。

当前大文件采用无损分片传输，由页面校验并恢复完整原文件。浏览器需要支持DecompressionStream与WebCrypto，通过HTTPS或localhost访问。下载页提供原名、原字节的文件；直接读取仓库旧`assets/*.glb`并不代表当前展示版本，集成当前版本请使用下载页或`asset-loader.js`及对应清单。左侧开门单仓仍复用原文件。
